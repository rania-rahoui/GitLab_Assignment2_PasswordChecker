Password Checker

Theme

Password Checker: checks a password against basic rules, gives it a strength score, and flags weak patterns.

Team

  • Rania Rahoui (@rania-rahoui): Rule checks
  • Yasmine Boutchiche (@yasmine2609): Strength score
  • Kamelia Magdoline (@Kamelia-Magdoline): Weak pattern detection

Features

  • Rule checks: length of at least 8, uppercase, lowercase, digit, special character
  • Strength score from 0 to 5 with a label (Weak, Medium, Strong)
  • Weak pattern detection: common passwords, repeated characters, sequences

How to run

pip install -r requirements.txt
pytest
